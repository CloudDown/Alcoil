# Alcoil

Unmaintained Windows prototype. Source only — binaries are not tracked.

- `scan.py` — Python entry
- `macro.au3` — AutoIt source
- `Alcoil.bat` / `install.bat` — local launchers
- `mousemoove.txt` — local data file (may be empty)
- `weapon/` — image assets (`M4A1-S (3).png`, `line(1).png`)

Do not commit `.exe` files.
